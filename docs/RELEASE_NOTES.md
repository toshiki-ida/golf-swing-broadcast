feature/ai-analysis の現場 PC (UltraStudio 4K Mini) 持ち込み版。PR #1 の動作確認用。
`tools/release.ps1` がビルド → `--ai-selftest` → zip → このノートの順で作る (先頭の 1 行はスクリプトが付ける)。

## 使い方

- Windows 10/11 64bit。zip を展開して `GolfSwingBroadcast\GolfSwingBroadcast.exe` を起動 (展開後 約 900 MB)
- ffmpeg / ffprobe、MediaPipe モデル、ONNX Runtime、日本語フォント、`config/rules.yaml` を同梱。`config/` を exe 同階層に置けばそちらが優先
- Desktop Video **12.0 以降** が必要 (`IDeckLinkVideoBuffer` を使用)。無い PC ではテストパターン入力で起動する
- 起動ログに DeckLinkAPI64.dll / API のバージョン、デバイス名、入力フォーマットを出す (現場での切り分け用)
- 動作確認: `GolfSwingBroadcast.exe --ai-selftest <動画> <出力dir>` → `<出力dir>\selftest_result.json` に OK/ERROR
  (`club_detector` と `labels` の項目で、検出器の有無とラベル保存先も確認できる)
- 現場手順: `docs/MIGRATION_CHECKLIST.md`。未署名のため SmartScreen / ウイルス対策ソフトの警告が出ることがある

## 前回 (2f326e9) からの変更

- **観測の無い区間を推定で埋める**: 信頼度ゲートで止めた区間を描かないのではなく、手首の軌跡 (毎フレーム取れる) と物理制約
  (クラブ長・シャフト角度の変化率) と過去の承認済み軌道のテンプレート (`_internal\models	rajectory_prior_<angle>.json`) から推定して描く。
  推定点は編集タブで中抜きの丸、AI 欄に「推定で補った区間」。送出・縦型動画では観測と同じ見た目。推定のままの点は学習データに入らない。
  精度は粗い (holdout のマスク評価で中央値 0.2〜0.5 身長 ≈ 100〜200 px、ダウンスイングと後方 (テンプレート無し) で大きい) ので、
  **確認して直す前提**。`"trajectory_fill": "off"` で従来どおり描かない
- **点の削除 (編集タブ)**: `Delete` で現在フレームの点を削除 (A/D やジョグで送りながら連続削除)、`Shift+Delete` 2 回で範囲削除、
  `Escape` で取消、`Ctrl+Z` / `Ctrl+Shift+Z` で戻す。消した区間は補間せず軌道が途切れる (スイングが分かれる)。
  タイムライン下段に点の位置、現在フレームの点は白で強調、フレーム番号の横に ●/○。右パネルにもボタンあり
- **信頼度ゲートの見直し**: 「手元接続 10%」を外し、静止・頭上・手首との距離のばらつき・速度比・手の動きの条件に替えた。
  tune 11 本の区間単位で正しい区間の通過 17/25 → 24/25、誤った区間の通過 2/18 → 1/18。閾値は `config/ai.json`
  (exe 同階層に置けば `_internal/config/ai.json` より優先) と settings.json の `ai.gate` で再ビルドなしに調整できる
- **編集タブに区間ごとの指標を表示**: AI 欄に「ゲート: 観測≥6f …」の閾値と、区間ごとの値・描画/未描画・止まった理由。
  「全区間を描く (ゲート無視)」ボタン (Undo 可)。クリップを選び直しても保存済みの結果が出る
- **縦型動画の注記を廃止**: 「軌道: 信頼度不足」「一部区間のみ」は動画に入れない。描ける区間だけ描き、状態は編集タブにのみ表示
- **学習データ**: 自動生成のあと人が削除した点を誤検出 (negative) として `<プロジェクト>\datasets\clubhead\` に記録。
  保存先はプロジェクトフォルダ側 (exe を差し替えても残る)。settings.json の `ai.collect_labels` で停止可
- **再学習ツール (開発 PC 用)**: `tools
etrain.ps1` が棚卸し → 学習 → holdout で従来 / 現行 / 新モデル比較 → レポートを一括で行う
- **同梱モデルは前回と同じ `clubhead.onnx` (12 点学習)**: 現場データ 11 本 (510 点) で再学習したモデルを holdout 8 本で比べたが、

## 現場での操作上の注意

1. **軌道は必ず確認・修正してから書き出す。** 自動生成は候補であって完成品ではない。確認動画 (編集タブのプレビュー) で
   ヘッドの位置を目で追い、ずれた点は動かす・消す、未描画区間は手で足す。信頼度不足と出たクリップは手描きで作る
2. 書き出した軌道はそのまま学習データになる。間違った点を残したまま書き出すと間違いを学習するので、
   「書き出す = この軌道で良いと承認した」つもりで扱う。やり直したら再書き出しで上書きされる
3. 撮影方向が「判定できません」になったときは手動で 後方 / 正面 を選んでから縦型書き出しをする (指標とコメントが変わる)
4. HFR 2x 収録 (29.97fps 記録) は自動で 1/2 速スローとして扱う。別カメラの 29.97/30fps 等速素材を取り込むときは
   settings.json の `"ai": {"source_kind": "external_30p"}` にする
5. 検出モードで軌道が明らかにおかしくなる素材があれば `"club_detector": "off"` にして同じクリップをやり直し、
   どちらが良かったかをクリップ名と一緒に控える (学習データの優先順位を決める材料になる)
6. 収録後に持ち帰るもの: `<プロジェクトフォルダ>\datasets\clubhead\`、`analysis\`、`startup.log`、
   起動ログの `[DeckLink]` 行 (Desktop Video のバージョン)
